Demo 2: Card Grid Layout

Click any card to flip it. Grid dynamically generated with shuffle!

Grid Size: 3x3 (9 cards) Pairs: 4 (8 cards + 1 single)

How it Works:

  • Data Structure: Array of card objects with id, name, and emoji
  • Doubling: Each card appears twice (pairs) using spread operator
  • Shuffling: Fisher-Yates algorithm randomizes card positions
  • Rendering: Dynamic creation of card elements from data
  • Grid Layout: CSS Grid with responsive columns

Key Code:

// Card data
const cards = [
  { id: 1, name: 'cat', emoji: '🐱' },
  { id: 2, name: 'dog', emoji: '🐶' }
];

// Double and shuffle
const gameCards = [...cards, ...cards];
const shuffled = shuffle(gameCards);

// CSS Grid
#card-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}
