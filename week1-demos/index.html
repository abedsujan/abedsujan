🎮 Week 1 Demos - Memory Game

Foundation Project Teaching Materials

📚 About These Demos

These four progressive demos teach all Week 1 milestone features for the Memory Game project. Each demo builds on the previous one, introducing new concepts and techniques. Perfect for live coding demonstrations and student reference.

✨ Week 1 Learning Objectives

🃏 Flippable Cards CSS 3D transforms & animations
📊 Card Grid CSS Grid layout & responsive design
🔢 Move Counter Track user interactions
⏱️ Game Timer Implement timing with setInterval

🎯 How to Use

For Instructors:

  • Use Demo 1-3 for live coding sessions
  • Demo 4 as reference and debugging aid
  • All demos are self-contained (no build required)
  • Source code is well-commented for learning

For Students:

  • View each demo to see features in action
  • Read source code to understand implementation
  • Use as reference when building your own project
  • Experiment by modifying values and seeing results
