Click cards to increment the move counter. Timer starts on first card flip!

How it Works:

  • Move Counter: Increments each time a card is revealed (flipped to back)
  • Game Timer: Starts when the first card is flipped
  • Timer Format: Displays as minutes:seconds (e.g., 1:23)
  • setInterval: Updates timer every second (1000ms)
  • Game State: Tracks if game has started, is paused, etc.

Key Code:

// Move counter
let moveCount = 0;
function incrementMoves() {
    moveCount++;
    updateDisplay();
}

// Timer with setInterval
let startTime, timerInterval;
function startTimer() {
    startTime = Date.now();
    timerInterval = setInterval(() => {
        const elapsed = Math.floor((Date.now() - startTime) / 1000);
        const minutes = Math.floor(elapsed / 60);
        const seconds = elapsed % 60;
        displayTime(minutes, seconds);
    }, 1000);
}
